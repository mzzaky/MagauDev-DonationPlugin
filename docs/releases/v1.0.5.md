# Magaudev Donations 1.0.5 — 31 Oktober 2026

Rilis companion plugin terpisah, skema 1, pasangan tema magaudev >=1.0.5. Fitur aktual dan batas operasional ada pada README/CHANGELOG dan panduan setup. Ringkasan bruto dikurangi refund; fee/net belum tersedia, tidak diestimasi sebagai aktual.

Paket: `build/magaudev-donations-1.0.5.zip`, root `magaudev-donations/`. Plugin tidak memerlukan tema untuk webhook, data, cron, REST atau diagnostik wp-admin. Tanpa plugin, tema menampilkan unavailable dan menyembunyikan menu panel donasi.

Urutan pemasangan: backup → plugin → aktifkan/migrasi → tema 1.0.5 → konfigurasi sandbox → pilih kanal aktif → validasi → buka penerimaan. Default paused, tidak otomatis production. Tidak ada migrasi schema tema.

Rollback: jeda donasi baru, simpan kedua paket dan backup, pertahankan plugin aktif untuk webhook saat rollback tema. Jangan menghapus tabel atau uninstall untuk rollback. Bila plugin dinonaktifkan, webhook tidak tersedia: aktifkan kembali dan rekonsiliasi sebelum membuka pembayaran baru. Mengganti salt WP memutus resume token terenkripsi; pertahankan key environment dan encryption key untuk data lama.

Validasi akhir dan status Git dicatat pada dev-log; pengujian gateway menggunakan double/database terisolasi. Sandbox nyata/webhook eksternal dan produksi belum diverifikasi tanpa kredensial dan endpoint HTTPS publik. Tidak melakukan refund/cancel nyata, tunnel, deployment atau perubahan merchant production.
